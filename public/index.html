API routes

API prefix: /api/v1

  • GET/api/v1/healthHealth Check of server
  • GET/api/v1/productsProduct list
  • POST/api/v1/productsCreate Product
  • GET/api/v1/products/:idGet Product By ID
  • PATCH/api/v1/products/:idProduct Update
  • DELETE/api/v1/products/:idProduct Delete
